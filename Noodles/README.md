Part 2: Refinement and Iteration

Refinement of movement and camera systems

Improvement of level interactions and game feel

Evidence of iteration based on playtesting

Part 3: Event Architecture
Event-based communication between game systems

Proper game state management throughout the experience

Manager systems coordinating gameplay elements

Decoupled architecture demonstrating professional code organisation

Part 4: Complete Game Loop
Full game flow from start to completion

Main menu, gameplay, and end states

Win and loss conditions with appropriate feedback

Restart or continue functionality

Part 5: Polish and Presentation
Integrated audio systems with sound effects and music

Visual feedback supporting gameplay actions

Performance optimisation ensuring smooth gameplay

Professional UI systems supporting all game states

Modular code following C# conventions and object-oriented principles

Properly organised project with clear folder structures

Consistent code formatting and documentation throughout

Part 7: Technical Document
Complete technical documentation of systems and architecture

Evidence of playtesting and iteration based on feedback

Key code snippets with explanations of AI and event systems
